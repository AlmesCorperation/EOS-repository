# Extended Open Source (EOS) Repository

Welcome to the official EOS framework and **Extended GNU Affero General Public License (EAGPL) v1.0**.

## 🛡️ What is EOS?
Extended Open Source (EOS) is **not** open source. It is a higher level of software license that continues where traditional copyleft ends. EOS is all about protecting humans who are making stuff, ensuring total reciprocity in exchange for their work from anyone who makes money using their code.

## 📄 The EAGPL v1.0 License
The projects of this ecosystem run on the **EAGPL v1.0** license. By copying any piece of code from an EAGPL licensed repository, your whole project will need to be public and open, regardless of the fact that you did not make any changes and even if your project is paying.
